# ClaimAuto MVP 전략: 최고의 트레이드오프 찾기

---

## 🎯 PART 1: MVP가 풀어야 할 문제

### 사용자 Pain Point 순서

```
1순위: "내가 얼마를 받을 수 있는가?" 
       → 환급액을 모름 / 헬스장이 부당 계산
       → 손실액: 평균 50~100만원

2순위: "법적으로 어떻게 요구하는가?"
       → 말하는 법을 모름 / 서면 통보 안 함
       → 손실: 상대방이 무시 → 진행 불가

3순위: "절차가 뭔가?"
       → 다음 단계를 모름 / 막혀서 포기
       → 손실: 절반이 소비자원 신청 못 함

4순위: "법적으로 이길 수 있는가?"
       → 자신감 부족 / 변호사 두려움
       → 손실: 시작조차 못 함
```

## 💡 PART 2: 각 기능별 자동화 검토

### 기능 1️⃣: 환급액 계산

#### 현재 상태 (자동화 전)

```
사용자가 할 일:
1. 인터넷에서 "헬스장 환급 계산" 검색
2. 공정거래위원회 고시 56조 찾아 읽기
3. 기이용료 공식 이해: (월요금 ÷ 30) × 이용일수
4. 케이스 분류 (폐업? 단순변심? PT?)
5. 손으로 계산
6. 다시 확인
7. 검산

소요 시간: 30분
정확도: 70% (실수할 가능성)
```

#### 자동화 후 (MVP)

```
입력:
- 계약금: 600,000원
- 월요금: 50,000원
- 계약일: 2024년 1월 15일
- 해지일: 2024년 3월 1일
- 상황: 단순 변심

출력:
- 이용일수: 45일 (자동 계산)
- 기이용료: 75,000원 (자동 계산)
- 위약금: 60,000원 (자동 계산)
- 최종 환급액: 465,000원 ✅
- 법적 근거: 공정거래위원회 고시 제56조

소요 시간: 2분 (입력만)
정확도: 99.9%
```

#### Trade-off 분석

```
【 자동화 비용 】
개발 시간: 8시간 (계산 로직 + 테스트)
유지보수: 거의 없음

【 자동화 가치 】
1. 사용자 시간 절약: 30분 → 2분
2. 정확도 향상: 70% → 99%
3. 자신감 제공: "정확한 금액이니까"
4. 무료 / 무한정 사용 가능

【 위험성 】
❌ "이 계산이 틀렸어?" 불만 가능
→ 근거를 명확히 제시 (공정거래위원회 고시)
→ "사용자 입력값 기준이므로 확인 바람" 주석

【 결론 】
✅ 반드시 자동화 해야 함
✅ MVP의 핵심 기능
✅ 법적 위험 거의 없음 (계산만)
```

### 기능 2️⃣: 카톡 내용증명 PDF 자동 생성

#### 현재 상태 (자동화 전)

```
사용자가 할 일:
1. Word/한글 열기
2. 내용증명 템플릿 검색
3. 수동으로 정보 입력:
   - 발신자/수신자 정보
   - 계약 내용 (언제, 얼마, 기간)
   - 법적 근거 (조항 적기)
   - 환급액 계산식
   - 요구사항
4. PDF로 저장
5. 최종 검토

소요 시간: 30분 ~ 1시간
실수율: 30% (정보 빠짐, 오입력)
```

#### 자동화 후 (MVP)

```
사용자 입력:
- 본인 이름, 주소, 연락처
- 헬스장 이름, 대표자, 주소, 연락처

앱이 자동 생성:
┌─────────────────────────────────┐
│     내용증명우편 청구서         │
└─────────────────────────────────┘

【 발신인 】
이름: 사용자이름
주소: 사용자주소
연락처: 사용자연락처

【 수신인 】
상호명: 헬스장이름
대표자: 대표자명
주소: 헬스장주소
연락처: 헬스장연락처

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
제목: 헬스장이름 회원권 계약 해지 및 환급금 청구서
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

저는 2024년 01월 15일 귀사의 헬스장에서
12개월 회원권(결제금액: 600,000원)을 계약하였습니다.

그런데 개인적인 사정으로 2024년 03월 01일에
계약을 해지할 의사를 귀사에 통보했습니다.

이용 기간은 2024년 01월 15일부터 2024년 03월 01일까지
약 45일간이며, 당시 월요금은 50,000원입니다.

【 법적 기준에 따른 환급액 계산 】

기이용료 = (월요금 50,000원 ÷ 30일) × 45일 = 75,000원
위약금 = 계약금 600,000원 × 10% = 60,000원

따라서 환급액 = 600,000원 - 75,000원 - 60,000원
            = 465,000원

【 근거 법규 】
1. 방문판매 등에 관한 법률 제31조
2. 공정거래위원회 고시 제56조
3. 약관의 규제에 관한 법률 제6조

따라서 귀사는 2024년 03월 20일까지
환급금 465,000원을
제 계좌로 환금할 것을 명확하게 요청합니다.

만약 위의 기한 내에 환금하지 않으면
한국소비자원에 분쟁조정을 신청하고,
추후 소액소송 등 법적 조치를 취할 수 있음을
알려드립니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2024년 03월 15일

발신인: 사용자이름
[도장 그림 또는 서명]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

출력: PDF 다운로드 버튼

소요 시간: 5초 (앱이 생성)
실수율: 거의 0%
```

#### Trade-off 분석

```
【 자동화 비용 】
개발 시간: 12시간 (PDF 생성 라이브러리 + 테스트)
유지보수: 낮음 (템플릿 수정만)

【 자동화 가치 】
1. 시간 절약: 1시간 → 5초
2. 정확도: 70% → 98% (형식)
3. 전문성: "이게 정말 법적으로 유효한가?" 불안감 제거
4. 즉시 사용 가능: "지금 바로 카톡 보낼래"
5. 배송료 절약: 우체국 비용 4천원 절약

【 위험성 】
❌ "이 내용증명이 법적으로 유효한가?"
→ "우체국이 증명하지는 않지만, 카톡 읽음 표시로 증명됨"
→ "법원에서 충분한 증거로 인정" 명시

❌ "개인정보가 PDF에 노출되는 건 아닌가?"
→ 사용자가 다운로드 후 본인이 발송
→ 앱은 저장 안 함 (privacy by design)

【 결론 】
✅ 반드시 자동화 해야 함
✅ MVP의 핵심 기능
✅ 법적 위험 낮음 (형식 제공만)
✅ 실제 효력이 높음 (카톡 기록)
✅ 개발 난이도 중간 (PDF 라이브러리)
```

### 기능 3️⃣: 절차 가이드 (체크리스트)

#### 현재 상태 (자동화 전)

```
사용자가 할 일:
1. "헬스장 환불 절차" 검색
2. 블로그/카페에서 정보 찾기
3. 뒤죽박죽 정보 중 맞는 거 찾기
4. 불안감 (이게 맞나?)

예시:
- 어떤 블로그: "직접 협상만 하면 된대"
- 어떤 카페: "무조건 소비자원 가야 한대"
- 어떤 댓글: "내 경우는 환금받지 못했어"

결과: 혼란, 포기

소요 시간: 1시간 (검색 + 읽기 + 혼란)
신뢰도: 40% (정보가 맞는지 모름)
```

#### 자동화 후 (MVP)

```
앱이 제시:

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
당신의 상황: 헬스장 단순변심 (3개월 이용 후)
예상 환급액: 465,000원 ✅
환급 가능성: 95% (위약금만 공제)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【 지금 해야 할 일 】
STEP 1️⃣  직접 협상 (아직 안 했다면)
  □ 헬스장 담당자에게 카톡/전화
  □ "계약을 해지하고 환급받겠습니다"
  □ 기한 제시: "3월 20일까지"
  □ 카톡 기록 스크린샷
  
  예상 결과: 성공률 80%
  시간: 하루 (담당자 답변 시간)

STEP 2️⃣  카톡 내용증명 발송 (거절할 경우)
  □ 앱에서 PDF 다운로드
  □ 카톡으로 헬스장에 발송
  □ 읽음 표시 될 때까지 대기
  □ 스크린샷 저장
  
  예상 결과: 성공률 50%
  시간: 1일

STEP 3️⃣  소비자원 신청 (여전히 거절)
  □ 1372 전화
  □ 분쟁조정 신청
  □ 필요 서류 제출 (앱에서 체크리스트)
  
  예상 결과: 성공률 70%
  시간: 2-4주

STEP 4️⃣  분쟁조정위원회 (소비자원 불성립)
  □ 위원회 신청
  
  예상 결과: 성공률 95%
  시간: 2-4주

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【 현재 위치 】
당신은 STEP 1️⃣  단계입니다

【 다음 일정 】
"3월 20일까지" 기한을 설정했으므로,
카톡 기록을 하루 종일 확인하세요.

만약 3월 20일까지 응답이 없으면
STEP 2️⃣ 로 진행하세요.

【 법적 조언 】
"환금 불가" 약관은 무효입니다.
방문판매법에 따라 언제든 해지 가능합니다.
자신감을 갖세요! 당신은 이길 수 있습니다! 💪

소요 시간: 5분 읽기
신뢰도: 99% (공정거래위원회 기준)
행동 가능성: 80% (단계별 명확)
```

#### Trade-off 분석

```
【 자동화 비용 】
개발 시간: 4시간 (조건부 로직 + 디자인)
유지보수: 낮음 (절차 변경 없음)

【 자동화 가치 】
1. 혼란 제거: "뭘 해야 하나?" 즉시 답변
2. 자신감: "이 절차가 맞나?" → "네, 맞습니다"
3. 행동 유도: 단계별 체크리스트 (실행력)
4. 성공률 제시: "95% 이길 수 있어"

【 위험성 】
❌ "환금 불가" 약관은 무효 → 절대 맞음
❌ 성공률 제시 → 구체적 판례 기반이면 OK

【 결론 】
✅ 자동화 해야 함 (설명 편의성)
✅ MVP의 중요한 기능 (사용자 신뢰)
✅ 법적 위험 거의 없음 (정보만)
✅ 개발 난이도 낮음 (조건부 로직)
```

### 기능 4️⃣: 소비자원 신청 자동화?

#### 현재 상태

```
사용자가 할 일:
1. 1372 전화
2. 상담원과 대화 (10분)
3. "분쟁조정 신청하겠습니다"
4. 한국소비자원 웹사이트 방문
5. 회원가입 / 로그인
6. 분쟁조정 신청 클릭
7. 정보 입력:
   - 계약자 정보
   - 사업자 정보
   - 분쟁 내용
   - 첨부 파일 (계약서, 영수증, 내용증명)
8. 제출

소요 시간: 30분
```

#### 자동화 제안

```
❌ 이건 자동화하면 안 됨!

이유:
1. 개인정보 보호 (이름, 주소, 연락처 수집 문제)
2. 법적 책임 (앱이 신청한 것처럼 보일 수 있음)
3. 사용자 동의 문제 (개인정보 위탁 동의)
4. 유지보수 (소비자원 시스템 변경 시)

대신:
✅ 링크 제공: "한국소비자원 분쟁조정 신청"
✅ 체크리스트: "필요한 서류는?"
✅ 가이드: "어떻게 입력하나?"
```

### 기능 5️⃣: 대면 매뉴얼

#### 현재 상태

```
사용자가 할 일:
1. 헬스장에 직접 방문
2. 담당자를 찾음
3. "뭐라고 말할까?" 생각하다가
4. 버벅거리거나 감정적으로 말함
5. "환금 불가"라는 회피 답변

결과: 실패, 신뢰 실추
```

#### 자동화 후 (MVP)

```
앱이 제시:

【 대면 전 준비 (5분) 】
□ 계약서 준비
□ 영수증 준비
□ 본인 신분증
□ 계산기 (검증용)

【 말하는 순서 】

1. 인사 (1분)
"안녕하세요. 계약 관련 문제가 있어서 왔습니다."

2. 상황 설명 (2분)
"20○○년 ○월 ○일에 12개월 회원권(○○○,○○○원)으로
계약했는데, 개인사정으로 해지하려고 합니다.
아직 3개월만 이용했거든요."

3. 계산식 제시 (2분)
"법적으로 이렇게 계산됩니다.
기이용료: (월요금 ÷ 30) × 이용일수
위약금: 계약금 × 10%
그러면 환급액은 ○○○,○○○원입니다."

4. 근거 제시 (1분)
"공정거래위원회 고시 56조에 따르면 이게 맞습니다."

5. 요청 (1분)
"이 금액을 ○월 ○일까지 계좌로 환금해주세요."

6. 기록 (1분)
"그럼 이 내용을 카톡으로도 보내도 괜찮을까요?"

총 8분

【 상대방이 거절할 때 】
"법적으로 거절이 불가능합니다.
방문판매법 31조에 따라 계속거래는 중도에 얼마든지
해지할 수 있습니다.
혹시 더 이야기할 게 있으시면,
소비자원에 신청하겠습니다."

【 성공 신호 】
✅ "그럼 얼마예요?" → 협상 진입
✅ "생각해볼게요" → 긍정 신호
✅ "한두 달 기다려주세요" → 협상 중

【 실패 신호 】
❌ "환금 불가입니다" → 내용증명으로
❌ "그건 안 돼요" → 같은 내용증명으로
```

#### Trade-off 분석

```
【 자동화? 】
이건 사실 "자동화"가 아니라 "매뉴얼"이다.
스크립트, 시나리오, 대사를 제공하는 것.

【 비용 】
개발 시간: 2시간 (체크리스트 + 시나리오)
유지보수: 거의 없음

【 가치 】
1. 자신감: "이 순서대로 하면 되겠네"
2. 실패 감소: 버벅거림 방지
3. 성공률 향상: 체계적으로 설득

【 결론 】
✅ 포함해야 함 (사용자 신뢰)
✅ MVP의 보조 기능
✅ 개발 난이도 매우 낮음 (텍스트만)
```

## 💎 PART 4: MVP 사용 시나리오

### 실제 사용 흐름

```
【 Day 1: 헬스장에서 환금 받지 못함 】
"아... 손해야. 어떻게 하지?"
→ ClaimAuto 앱 다운로드

【 5분 뒤 】
"어? 내가 465,000원을 받을 수 있다고?"
→ 환급액 자동 계산으로 확신 생김

【 30분 뒤 】
"내일 헬스장에 가서 말해야겠다"
→ 대면 매뉴얼 읽고 시뮬레이션

【 Day 2: 헬스장 방문 】
"안녕하세요. 법적으로 465,000원을 받을 수 있는데..."
→ 시나리오대로 진행

헬스장: "음... 생각해봐야겠어요"
→ 거절하지만 진지하게 받아들임

【 Day 3 】
"역시 안 되네. 뭘 해야 하지?"
→ 앱: "STEP 2로 진행하세요. PDF를 다운로드하세요"

【 5분 뒤 】
PDF 다운로드 → 카톡으로 발송
"이제 우체국 내용증명처럼 기록이 남았네"
→ 전문성 있는 PDF 때문에 심리적 안정

【 Day 4 】
헬스장이 읽음 표시
→ 앱이 알려줌: "읽음 표시됐어요! 스크린샷 하세요"

【 Day 10 】
헬스장이 답장 없음
→ 앱이 가이드: "STEP 3: 소비자원 신청하세요"

【 3주 뒤 】
소비자원이 헬스장에 연락
→ 앱에 진행 상황 입력

【 5주 뒤 】
헬스장이 "환금하겠습니다" 연락
→ 465,000원 입금

【 결과 】
✅ 법적 지식: 없음
✅ 변호사: 안 씀 (0원)
✅ 소요 시간: 5주 (그 중 앱 사용: 30분)
✅ 성공: YES
✅ 만족도: ⭐⭐⭐⭐⭐
```
