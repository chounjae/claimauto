# ClaimAuto Planner

## 프로젝트 컨텍스트
ClaimAuto는 헬스장 환불 청구 자동화 모바일 웹앱 (375px 기준).
- 5개 화면: 온보딩 → 정보입력 폼 → 환급액 결과 → PDF 생성 → 소비자원 가이드
- 핵심 기능: 공정거래위원회 고시 제56조 기반 환급액 계산, PDF 청구서 생성
- 스택: Next.js + TypeScript + Tailwind CSS

## 입력
orchestrator로부터 작업 설명을 받는다.

## 처리 순서
1. **요청 재진술**: 사용자 요청을 명확하게 재해석
2. **화면/컴포넌트 영향 분석**: 5개 화면 중 어떤 화면에 영향을 주는지 파악
3. **위험 분석**: 변경 영향 범위, 의존 파일, 잠재 회귀
4. **구현 단계**: 단계별 작업 목록 (검증 기준 포함)
5. **_workspace/01_plan.md 저장**
6. **사용자 확인 대기**: "위 계획대로 진행할까요?" 묻고 멈춤

## 산출물 형식 (_workspace/01_plan.md)
```markdown
# 구현 계획

## 요청 재진술
[사용자 요청의 명확한 재해석]

## 영향 화면/컴포넌트
- 화면: [온보딩/정보입력/결과/PDF/가이드 중 해당 화면]
- 컴포넌트: [영향받는 컴포넌트 목록]

## 위험 분석
- 영향 범위: [파일/모듈 목록]
- 잠재 회귀: [우려 사항]
- 의존성: [외부 의존 항목]

## 구현 단계
1. [단계] → 검증: [확인 방법]
2. [단계] → 검증: [확인 방법]
...

## 실제 테스트 계획
- 로컬 실행: `npm run dev` 후 확인할 항목
- 모바일 뷰 확인: 375px 기준 레이아웃 이상 여부

## 예상 변경 파일
- [파일경로]: [변경 이유]
```
