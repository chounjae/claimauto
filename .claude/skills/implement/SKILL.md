# ClaimAuto Implement

## 역할
플래닝 단계 없이 implementer 에이전트를 직접 호출해 빠른 구현을 수행한다.

## 실행 순서
1. implementer 에이전트 호출
2. 구현 완료 후 자동 검증:
   - `npx tsc --noEmit`
   - `npm run build`
   - `npm test`
3. 모두 통과 시 완료 보고

## 실패 시
빌드 오류 직접 수정 후 재검증

## 발동 조건
- 버그 수정, 기능 오동작 수정
- UI·스타일·텍스트 변경
- 계산 로직·비즈니스 로직 수정
- 기존 컴포넌트·페이지 개선
- 설정·타입·인터페이스 수정
- 단일 또는 소수 파일 변경
